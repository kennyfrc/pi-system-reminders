# pi-system-reminders

ai21-style transient reminder injection for Pi — a durability state machine on the context event. Reminders are re-derived per evaluation and pinned to a clock edge (turn:start | call:every | tool:error). Never persisted; never accumulate in history.

## Install

```bash
pi install git:github.com/kennyfrc/pi-system-reminders
```

Extracted from the jetdraft-pi-extensions monorepo.
